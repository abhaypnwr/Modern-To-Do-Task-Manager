# Modern To-Do Task Manager

## 📌 Project Overview

Modern To-Do Task Manager is a simple and responsive web application that helps users organize their daily tasks efficiently. It allows users to add, complete, and delete tasks while automatically saving them in the browser using Local Storage. The application is built using HTML, CSS, and JavaScript, making it lightweight and easy to use without requiring a backend.

---

## 🚀 Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Automatically save tasks using Local Storage
* Responsive design for desktop and mobile devices
* Clean and user-friendly interface

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Browser Local Storage API

## ⚙️ Installation and Usage

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension (optional but recommended).
4. Open `index.html`.
5. Right-click and choose **Open with Live Server**, or open the file directly in your browser.

---

## 📖 How to Use

1. Enter a task in the input field.
2. Click the **Add** button to add the task.
3. Click on a task to mark it as completed or incomplete.
4. Click the **Delete** button to remove a task.
5. Your tasks are automatically saved and remain available even after refreshing the page.
